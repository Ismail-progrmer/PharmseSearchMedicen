# نظام صيدلية الأمان – Al Aman Pharmacy (التصميم المرئي)

مشروع C# Windows Forms يحتوي على **التصميم المرئي الكامل لست واجهات** لنظام
صيدلية الأمان، وفق الهوية البصرية الموحدة (أزرق داكن / أزرق فاتح / أبيض،
زوايا دائرية، خط Tahoma، اتجاه عربي كامل RightToLeft).

> ملاحظة مهمة: هذا المشروع **للتصميم فقط** ولا يحتوي أي قاعدة بيانات أو SQL أو
> Oracle أو عمليات CRUD أو منطق أعمال (Business Logic). جميع أحداث الأزرار
> هي أحداث تنقل تجريبية بين الواجهات الست فقط، والبيانات داخل الجداول
> **بيانات تجريبية مؤقتة** للعرض فقط.

## متطلبات التشغيل (Visual Studio 2022)

- Visual Studio 2022 **v17.8 أو أحدث** (لدعم .NET 8 SDK).
- الهدف: **net8.0-windows** مع `UseWindowsForms` (بنية csproj بنمط SDK).
- لا يحتاج أي حزم خارجية (NuGet) — كل العناصر أصلية Windows Forms، ولا يستخدم
  أي مكون يتطلب إصداراً أحدث من Visual Studio 2022.

## طريقة الفتح والتشغيل

1. افتح الملف `AlAmanPharmacyUI.sln` من Visual Studio 2022.
2. اضغط F5 (أو زر Start) — تبدأ الواجهة الرئيسية مباشرة.
3. كل واجهة تعمل أيضاً بشكل مستقل: اختر أي Form ثم اضغط Ctrl+F5.

## الواجهات الست وخريطة التنقل التجريبي

| الواجهة | الملف | الانتقال منها |
| --- | --- | --- |
| الرئيسية | `Forms/MainForm` | زر «صيدلية» → البحث عن الأدوية، زر «مستخدم» → تسجيل الدخول |
| البحث عن الأدوية | `Forms/SearchMedicineForm` | جدول نتائج مع بيانات تجريبية |
| تسجيل الدخول | `Forms/LoginForm` | زر «دخول» → لوحة التحكم (دون تحقق فعلي) |
| لوحة التحكم | `Forms/DashboardForm` | بطاقة الأدوية → إدارة الأدوية، بطاقة الصيدلية → إدارة الصيدلية، «تسجيل الخروج» → الرئيسية |
| إدارة الأدوية | `Forms/ManageMedicinesForm` | أزرار إضافة/تعديل/حذف (تصميم فقط) وجدول ببيانات تجريبية |
| إدارة الصيدلية | `Forms/ManagePharmacyForm` | بيانات الصيدلية + أوقات العمل أيام الأسبوع (تصميم فقط) |

## جدول DataGridView الأصلي

واجهتا «البحث عن الأدوية» و«إدارة الأدوية» تستخدمان عنصر `DataGridView`
الأصلي، منشأً بالكامل داخل ملفات `Designer.cs` وضبط خصائصه بخصائص Windows
Forms الأصلية فقط:

- اتجاه عرض RTL (موروث من `ChromeForm` عبر `RightToLeft.Yes`).
- ترويسة الأعمدة **بالأزرق الداكن** `RGB(30,78,140)` ونص أبيض Bold.
- تلوين الصفوف بالتناوب: أبيض / أزرق فاتح `RGB(234,243,252)`
  (عبر `AlternatingRowsDefaultCellStyle`).
- ضبط عرض الأعمدة تلقائياً: `AutoSizeColumnsMode = Fill` مع `FillWeight`
  لكل عمود + `MinimumWidth` لحماية الأعمدة الضيقة.
- منع الإضافة اليدوية: `AllowUserToAddRows = false`، ومنع الحذف ومنع تعديل
  الحجم، ومنع التعديل المباشر: `ReadOnly = true`.
- تحديد الصف بالكامل: `SelectionMode = FullRowSelect` مع `MultiSelect = false`.
- حدود خفيفة: `GridColor = RGB(214,224,239)` مع `BorderStyle = None`.
- ارتفاع الترويسة 44 والصف 38، وخط Tahoma 9.75 (Bold للترويسة).

## البيانات التجريبية

صفوف الجداول التجريبية تُضاف في دالة `LoadDemoData()` داخل ملف
`Forms/SearchMedicineForm.cs` و`Forms/ManageMedicinesForm.cs`، وعليها تعليق
يوضح أنها للعرض فقط. عند الربط بقاعدة البيانات تُحذف هذه الدالة وتُستبدل
بتغذية الجدول من نتيجة الاستعلام (انظر القسم الأخير).

## الهوية البصرية

- الأزرق الأساسي للأزرار وترويسات الجداول: `RGB(30, 78, 140)`
- لون العناوين: `RGB(23, 51, 94)`
- شريط العنوان: `RGB(201, 216, 238)`
- البطاقات: `RGB(234, 243, 252)` بإطار `RGB(159, 185, 220)`
- الصفوف المتناوبة: `RGB(234, 243, 252)`
- الخط: Tahoma (عناوين Bold)

## نقطة الربط المستقبلية مع Oracle

عند بناء النظام الفعلي لاحقاً:
- عمليات البحث والإضافة والتعديل والحذف تُربط على أزرار الواجهات الثلاث
  الأخيرة (`SearchMedicineForm`, `ManageMedicinesForm`, `ManagePharmacyForm`).
- حقول الجداول `DataGridView` جاهزة بالأسماء `colName`, `colPharmacy` ... إلخ
  ويمكن تغذيتها من `DataTable` ناتج عن استعلامات Oracle مباشرة عبر `DataSource`:
  ```csharp
  // مثال مستقبلي فقط (غير موجود في المشروع حالياً)
  dgvResults.DataSource = GetMedicinesFromOracle(medicineName, category);
  ```
- قوائم التصنيف والأوقات في `ComboBox` جاهزة ويمكن استبدال عناصرها بقيم من قاعدة البيانات.
